This is my attempt at revamping my old cybersecurity toolsuite and making it accessable on the web. 
Contains a few useful red team and blue team tools.



____________________________________________________________________________________________________
USAGE DISCLOSURE:
This toolsuite was designed for ETHICAL cybersecurity applications (pentesting & general cyber defense). While the tool can facilitate harmful interactions, **do not use CyberWeb with malicious intent**.
____________________________________________________________________________________________________

Installation:
Should install any dependencies needed automatically, and be ready to use out of the box. 

How to Use:
Run Cyberweb.bat - This will spool up the API and webservers and then start the actual web interface. Should work out of the box.
